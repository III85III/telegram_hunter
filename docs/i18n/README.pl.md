# TelegramHunter

**Polski**

TelegramHunter sprawdza nazwy użytkowników Telegram przez Telethon i NLTK, zapisując wyniki i postęp. Wymaga Python 3.10+: uruchom setup.bat, potem run.bat. Korzystaj z własnych kont, przestrzegaj limitów Telegram i chroń pliki sesji.

> Ta strona tłumaczy opis i instalację; nie zmienia języka interfejsu aplikacji.

## Wymagania

Python 3.10+ · Telegram · Internet

## Pobieranie kodu

```bash
git clone https://github.com/III85III/telegram_hunter.git
cd telegram_hunter
```

## Instalacja · Uruchomienie

**Windows**

```bat
setup.bat
run.bat
```

**Linux / macOS**

```bash
python3 -m venv venv
. venv/bin/activate
python -m pip install -r requirements.txt
python -c "import nltk; nltk.download('words')"
python hunter.py
```
